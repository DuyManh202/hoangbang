# Hoàng & Bằng — Wedding Invitation

Landing page thiệp cưới xây dựng bằng Next.js App Router.

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở http://localhost:3000 để xem trang. Dùng `npm run build` để tạo bản production và `npm start` để chạy bản đó.

## Cấu trúc

- `app/`: route chính, layout và stylesheet toàn cục.
- `components/`: từng khu vực của landing page.
- `data/wedding.js`: tên, lịch cưới, địa chỉ và thông tin hai gia đình.
- `public/images/`: ảnh dùng trên trang.
